# UK Study Guide — 영국 대학 진학 AI 진단 (학부·석사)

영국 학부(파운데이션·IYO)·석사(Direct·프리마스터) 진학 경로를 진단하는 무료 정보 가이드 페이지입니다. 특정 유학원·기관과 무관하며, 대학 순위는 QS World University Rankings 2027, 과정·요건 정보는 각 대학 및 운영 기관 공시 기준입니다.

## 주요 기능

- **학부 / 석사 트랙 선택** — 챗 형식의 단계별 질문으로 프로필 진단
- **영어 점수 환산** — TOEFL·PTE 점수를 IELTS 밴드로 자동 환산
- **특수 전공 직접 입력** — 입력한 전공명을 가장 가까운 계열로 매칭해 분석
- **패스웨이 로직** — 파운데이션 / IYO / A-level·IB (학부), Direct / 프리마스터 (석사) 자동 판정
- **파운데이션 유형 가이드** — 사설 · 자체 대학부설 · 입학보장형 비교와 성적별 추천
- **대학 공식 링크** — 추천 대학·전공별 공식 홈페이지와 코스 페이지로 바로 연결
- **결과 링크 공유** — 진단 결과가 URL 해시에 인코딩되어, 링크 전달 시 동일한 결과 페이지가 열림

## 기술 스택

- 단일 `index.html` (정적 페이지) — Tailwind CDN, Font Awesome, Pretendard Variable
- GitHub Pages 배포

## 면책

본 페이지는 정보 제공 목적이며, 입학요건·학비·비자 요건은 수시로 변경됩니다. 지원 전 반드시 각 대학 공식 입학처와 [Study UK](https://study-uk.britishcouncil.org/) · [GOV.UK 학생비자 안내](https://www.gov.uk/student-visa)에서 최신 정보를 확인하세요.
